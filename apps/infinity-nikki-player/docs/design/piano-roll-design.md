# MIDI 详情钢琴卷帘设计

公共 API、时间转换和浏览器渲染行为以 [`@strawberrybear/piano-roll` README](../../../../packages/piano-roll/README.md) 为准。本文只规定播放器的装配、数据兼容与设备验收。

## 页面组合

`MidiDetailPage.vue` 装配一个完整音轨工作区，包含多轨总览与按需详情。双击轨道后，底部按需出现非模态单轨浮层；此时单击其它轨道立即切换详情数据。浮层没有遮罩、焦点陷阱或窗口级滚轮监听，主区域的工具栏和滚动容器继续响应交互。

### 独立音轨窗口

总览工具栏的主题色“在独立窗口中打开”按钮将整个“总览＋详情”工作区分离为可移动、缩放、最小化的原生桌面窗口（pop-out / detachable panel）。窗口默认 1100×640，最小 720×480，不强制置顶；使用原生窗口装饰。子窗口确认数据就绪后，主页面才收起整个内嵌工作区，仅保留唤起／还原入口，不在两个窗口重复绘制。重复打开只唤起现有窗口；创建失败或 10 秒未就绪会恢复内嵌状态并显示具体错误。

内嵌和独立模式共用 `components/PianoWorkspace`，其中包含原有总览、轨道 Switch/Tooltip、筛选、操作帮助、选轨、详情高度手柄和 `PianoEditorPanel`；缩放控件使用同一个 antdv `PianoRollControls`。`features/piano-editor` 管理会话协议，`platform/tauri/pianoEditorWindow.ts` 适配 [Tauri WebviewWindow](https://v2.tauri.app/zh-cn/reference/javascript/api/namespacewebviewwindow/) 和定向事件。`piano-editor.html` 是专用轻量入口，不挂载主页面、不创建 Player、音频引擎、键盘模拟器或更新检查。

主页面始终拥有歌曲、预览时间和 seek 权威。选轨及布局属于唯一挂载的工作区；在独立窗口单击／双击轨道与主界面行为一致。切换详情歌曲会同步到现有独立窗口；切歌恢复对应歌曲的缩放偏好，切轨保留当前视口并沿用公共库的音域定位策略。异步加载期间覆盖旧工作区并禁用旧数据交互，新数据就绪后恢复面板布局；加载中的空文档不按空曲目关闭详情。窗口消息带 session、数据 revision 和递增序号，旧歌曲、旧窗口与重复操作不能提交到新歌曲。文档只在变化时发送，连续播放更新最多每 50ms 发送最新 transport，并携带采样时刻（performance.timeOrigin + performance.now）；暂停、倍速与 seek 立即发送。独立窗口按自己的 requestAnimationFrame 外推只读显示时间，并在两个控制器上直接绘制，不让 IPC 到达节奏决定显示帧率；不创建音频时钟或音频实例。两秒心跳只重发最近样本及其原始采样时刻，不重新读取 UI 缓存并生成新时间戳，避免主窗口后台采样较慢时周期性回退。没有新权威样本超过两秒时冻结展示；收到新样本后恢复，心跳不能延长过期样本的外推期限。视口回报每 100ms 合并一次，关闭时提交最终完整快照。不逐帧复制音符数组。拖拽只预览，松手通过原有 `usePianoDetailSeek` 提交一次。

原生关闭按钮和“还原到主窗口”都先回传最终视口，再销毁独立窗口。主页面恢复整个工作区，保留选轨、详情开关、空轨筛选、两个视图的时间缩放、详情音高缩放、各自 Follow 和双轴滚动，以及详情高度；尺寸不同产生的越界由公共控制器裁剪。开启 Follow 且播放中仍遵循真实播放位置。主窗口最小化或被独立窗口全屏遮挡时仍低频读取真实音频位置；独立窗口在权威采样之间外推显示位置，不创建高频后台计时器，也不改变音频调度。

离开 MIDI 详情路由会销毁独立窗口；主窗口关闭也清理子窗口。主页面刷新或失联时，子窗口的 10 秒租约到期后自行退出，不保留失效音轨。子窗口刷新会重新握手获取完整文档。窗口错误不会修改播放队列、音频调度或游戏按键状态。

### 自动切换与缩放控件

歌曲统计行最右侧的“自动切换”首次默认关闭，并在当前应用会话内保留设置。开启后使用 `router.replace` 跟随当前正在播放或暂停的歌曲；自动下一曲不会堆积浏览历史。关闭后可独立浏览其它详情。此开关只改变详情路由，不调用选曲或队列 API；鼠标悬停说明作用。

总览、内嵌详情和独立窗口复用同一个 antdv 缩放控件。控制器的真实 px/s 是唯一缩放状态；滑块通过公共 `timeZoomToSlider` / `sliderToTimeZoom` 可逆地映射为 0–100 的倍率刻度，同样翻倍占同样长度，低倍区域不会挤在左端。最左端严格等于一屏全曲，最右端等于控制器上限。手势以相邻采样的倍率作用于当前实际值，越过边界后反向立即响应，没有需要抵消的边界外虚拟值。方向键每次调整 5%，Home/End 到上下限；轨道底色通过主题 Slider token 统一加深。现有按曲目保存缩放的规则继续适用于独立窗口。

页面私有 `MidiDetailPage/pianoRollAdapter.ts` 负责纯数据转换，`usePianoDetailSeek.ts` 负责预览与歌曲绑定，`usePianoEditorWindow.ts` 管理平台会话。高度、选择、缩放保存及虚拟轨道挂载点逻辑与测试归入 `components/PianoWorkspace/`，不反向依赖页面。

键盘以真实白键为背层，黑键覆盖相邻白键接缝；E/F、B/C 直接相接。右侧等高半音网格不变，黑键中心和 C 音标签继续对应正确音高。

两个公共 Vue 实例接收同一份文档和外部播放状态，各自维护时间缩放、音高缩放、滚动、标尺、播放头和 Follow 状态。打开、关闭和切换轨道不更换总览实例。CSS 为打开的浮层保留可见空间，并给上方总览保留工具栏、标尺和一行轨道的空间，使总览自己的滚动条仍可操作。总览使用公共库的自动行高，浮层打开时音轨随剩余空间变矮，关闭或窗口增大后重新铺满；达到最小行高才纵向滚动。具体布局边界以公共包 README 为准。

Follow 的三段自动视口、手动浏览及切换由公共库负责，页面不从 `scroll` 通知推断用户意图。上下滑动及其小幅横向尾帧不会冻结播放画面；关闭 Follow 后允许播放头移出视野，页面不强行拉回。页面的 seek、缩放、选轨及尺寸变化通过公共控制器清理未确认的手势。具体状态与边界见公共包 README。

页面工具栏统一使用 antdv-next：Follow 使用带 Crosshair 图标的 `Button`，开启时使用主题填充态，时间/音高缩放使用带常驻文字标签的 `Slider`，关闭和图标按钮使用 `Tooltip`。完整可见的标签不重复套 Tooltip；轨道名称只有实际省略时才通过 `renderTrackLabel` 挂载 Tooltip。公共包通过 slot、`renderTrackToggle` 和 `renderTrackLabel` 提供框架无关的挂载点，页面不再给卷帘控件添加原生 `title` 或自绘同类控件；公共包的原生 fallback 仅供无 UI 框架的直接浏览器接入。

两处工具栏的标题与左侧操作组保留清晰间距；总览右侧依次放置筛选和操作帮助按钮，详情的关闭按钮固定在最右侧，关闭按钮使用 antdv `danger` 红色状态。`usePianoTrackHosts` 登记可见轨道的宿主挂载点，`PianoTrackHosts` 通过页面组件树中的 Teleport 渲染 Switch 和名称 Tooltip，继承应用 ConfigProvider 的主题及语言。轨道启用状态更新复用组件 key，保留键盘焦点；虚拟行移出可见区域或视图卸载时清理登记项和 Tooltip。`PianoTrackLabel` 也用于可能很长的详情标题，仅在实际省略时提示全文。

页面私有 `PianoRollHelpDialog` 提供帮助图标入口及 antdv Modal，按“查看音轨、缩放与跟随、定位与详情窗口”三组说明单双击、开关、空轨筛选、缩放持久化、滚动与 Follow、seek、浮层高度和只读边界。内容使用一套结构化模板及中英文 i18n；只管理帮助弹窗开关，不调用播放、文件或模拟按键接口。Escape、弹窗关闭按钮和底部完成按钮均可关闭帮助，详情视图保持原状态。

总览默认开启“隐藏没有音符的音轨”，通过公共视图的 `hideEmptyTracks` 仅筛选可见轨道行。筛选按钮使用主题填充态表示开启、普通态表示关闭；关闭筛选即可恢复全部轨道。有音符的已屏蔽轨道仍显示。筛选不修改完整文档、轨道启用状态、全曲时长、选中轨道或已经打开的详情；全部轨道都为空时显示空状态，工具栏仍可操作。

页面按 MIDI 文件名分别持久化总览时间缩放、详情时间缩放和详情音高缩放，保存在版本化的 localStorage 键中。读取失败、旧值损坏或存储不可用时回退公共库默认值；这些偏好不进入播放器设置，也不影响预览音频和游戏内按键模拟。

浮层高度由应用维护：拖动顶部边缘向上增高、向下减小。顶部边缘可聚焦，方向上/下每次调整 5%，按 Shift 调整 10%，Home/End 到达最小/最大高度，Escape 或 antdv 关闭按钮关闭浮层。指针捕获、取消、失焦均释放拖动状态。关闭和切换音轨保留高度偏好。

再次双击当前轨道也会关闭浮层；双击另一轨道则切换并保持打开。关闭判断使用公共事件提供的手势开始时选择，避免双击之前的单击已切换轨道而误关闭。关闭时清理高度拖动与 seek 临时预览，保留主界面选轨；无轨道时自动关闭，失效轨道事件不打开空浮层。

视图沿用公共包的浅粉默认主题，与应用当前品牌色 `#F7B7BE`、强调色 `#E36F86` 和暖白背景一致；音符、文字及播放头使用较深颜色保证辨识。主题覆盖方式以公共包 README 为准。滑块和双指缩放统一限制到完整曲目铺满时间区，容器改变时重新测量；主视图和浮层分别适配各自的可见宽度。公共库仍保留 `fitToSong()` API，播放器工具栏不重复提供该按钮。

## MIDI 适配

- Rust 的完整 `duration_ticks`、原始微秒 tempo map 和拍号 map 是曲谱时间事实；不通过最后一个音符或取整 BPM 替代。
- 轨道 ID 使用原始轨道索引的字符串。读取 `MidiInfo.tracks` 并合并轨道数量与事件轨号，因此无音符轨道也保留；优先展示 MIDI 原始 Track Name，缺失时使用已翻译的轨道序号。
- MIDI Track Name 没有统一字符集标记，Rust 优先按合法 UTF-8 读取；失败后尝试无错误的 Shift-JIS 解码，两者均失败才沿用有损 UTF-8 后备。该兼容策略用于旧日文 MIDI，不是对任意字符集的自动识别。曲库加载会重新解析源文件，旧配置不会覆盖轨名或每轨结束 tick。
- 每轨 `end_tick` 独立记录该轨完整结束位置，适配为公共轨道的 `startTick: 0` / `endTick`。总览粉色块仅表示本轨范围，保留区域间窄间距；空轨和短轨不会铺满全曲。旧数据缺少该字段时保留缺省值，由公共库回退到音符范围。全曲 `duration_ticks` 仍独立保留。
- 音符保留 Rust 稳定 ID，并优先用 `source_track` 绑定真实原轨号；旧 `track` 字段继续服务兼容路径，超过 255 轨时也不会串轨。旧缓存缺少 ID 时，按原始事件属性和事件顺序生成后备 ID。缩放、换轨和启用状态不会修改音符 tick。
- 旧缓存缺少完整结束 tick 时，通过已存时长反推 tick 并保留音符尾部，作为兼容后备；重新解析后的原始结束 tick 优先。
- 已有屏蔽配置使用原始轨号加一。该映射仅在 app adapter/store 内处理，公共文档只接收 `enabled` 和不透明轨道 ID。

轨道启用使用可辨识的切换开关，状态回传仍走原有屏蔽配置；开关不会触发轨道选择、浮层开关或播放定位。

## 预览播放与定位

公共组件所有 transport 和 seek 数值以秒为单位；本页在 store 边界转换为毫秒。只有当前预览曲与详情曲相同时，卷帘才显示真实播放头。查看另一首歌曲时指针停在起点，不跟随其它歌曲。

预览 feature 通过 `previewProgress.ts` 在可见页面的动画帧读取现有 AudioContext 位置，避免独立 16ms 定时器与屏幕绘制错拍；每次采样机会同时设置 250ms 兜底计时器，RAF 与计时器仅允许先到者采样并取消另一方。即使 WebView 报告可见但不再交付 RAF，也继续低频检查音频位置与曲终，保持自动下一曲；恢复绘制后不会留下第二个采样循环。采样器只决定读取时机，不生成音乐时间，也不改写音频或游戏按键调度。暂停、seek、切歌、销毁及可见性切换会取消待执行回调，旧回调不能重启已结束的会话。

拖拽期间 `seek-preview` 只更新本页的临时位置，两个视图同步预览，音频不反复跳转。取消时恢复外部播放时间；松手的 `seek` 提交一次定位。异步提交使用请求序号和歌曲身份检查，切换详情页后旧请求不能继续定位。

在非当前歌曲的详情里定位，会先停止旧预览音频，选择目标歌曲并在目标位置保持静止。它沿用包含此歌曲的当前队列，否则使用全部歌曲队列。在当前歌曲中定位则保留原播放/暂停状态。此流程只调用预览播放方法，不操作游戏内模拟按键调度器。

## 第一版边界

第一版只读，不提供新增、删除、移动、变长、力度、量化或撤销。轨道选择、启用和播放定位属于查看与预览交互，稳定 ID 为后续编辑和插件留下数据基础。

文件解析支持使用 PPQ 音乐时间制的 MIDI Format 0/1。SMPTE 时间制、异步 Format 2 和零 ticks-per-beat 会明确报错，避免以错误时间轴显示或播放。`source_track` 保留完整原始轨道索引，旧 `track:u8` 仅维持已有模拟按键协议的兼容语义。

页面文案使用 Vue I18n，位于 `src/i18n/locales/{zh-CN,en-US}.ts` 的 `midi.pianoRoll` 命名空间，并经公共组件 `labels` 传入。语言包在 `src/i18n/index.ts` 静态注册，跟随系统/应用语言，未知语言回退 en-US；新增语言须同时注册应用文案与 antdv-next 语言包。

## 验收

公共算法和浏览器行为测试属于公共包；应用发布前在 macOS/Windows Tauri 窗口执行以下交互验收：

1. 双击任意轨道打开浮层；单击其它轨道切换；再次双击当前轨道关闭，双击另一轨道保持打开；关闭按钮和 Escape 均可关闭，总览保留选中轨道。检查无音符轨道、长名字、打击乐混合通道，以及短轨/空轨的粉色区域范围与轨间间距。
2. 独立缩放和滚动两个视图，确认标尺可不同而同一播放时间对应一致。在最高时间缩放下反复上下滑动，中段播放头保持中线，琴键与音高网格同步上下移动；明确横向滑动达到四分之一屏只暂停所在视图的 Follow，小幅尾帧不冻结画面。关闭 Follow 后滚走，确认播放头可保持不可见，重新开启才返回自动视口。分别用滑块和双指缩放达到下限，确认时间区恰好铺满，不能继续缩小且没有额外横向滚动；缩小/放大窗口、调整浮层高度后结果仍正确。浮层内外滚轮分别作用于所属容器，并确认重新进入同一歌曲时恢复各视图上次缩放。
3. 拖顶部边缘、使用键盘调整、取消捕获、切换焦点和缩小窗口，确认主总览工具栏仍可使用，页面无全屏遮罩。
4. 播放中与暂停时分别点击标尺、拖动手柄、取消拖动；确认只在提交时定位，起点/终点手柄完整可见且点击不跳位。检查 0.5x、1x、2x、暂停后定位再恢复。
   在低时间缩放和刻度密度切换临界值附近观察标尺：线条连续平移，文字不在视口中间闪现或消失，速度／拍号变化处不发生整批刻度切换；1×、2× DPR 下分别验证总览与详情。
5. 当前播放 A 时查看 B，确认 B 不显示 A 的播放头；在 B 定位后保持 B 静止。连续切换详情页/快速 seek，确认旧请求不覆盖新曲。
6. 屏蔽并重新启用轨道，切歌后返回确认配置保留；游戏内演奏的按键序列、暂停、继续和停止行为保持兼容。

页面私有自动化测试覆盖空轨、原始时间元数据、旧缓存、稳定 ID、256+ 轨、20 万音符、屏蔽映射，以及快速 seek、异步绑定、换页和卸载失效。公共浏览器回归还覆盖 Follow 的“进入中线、保持中线、曲尾释放”状态机和宿主轨道开关挂载点。
