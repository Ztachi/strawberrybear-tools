# 键盘录制工作区

## 用户流程

从 MIDI 编辑器的“键盘录制”按钮打开当前音轨；虚拟键盘页同名入口创建空项目并打开工作区。主窗口与独立 MIDI 编辑窗口复用全内容区抽屉，录制内容应用后才更新宿主。每次录入一个音轨，其他启用轨可作为伴奏；试听满意后回到 MIDI 编辑器继续完善音符、时长与力度。

抽屉按页面组织：顶部保持一行，左侧仅显示音轨名，复用 PlayerSongTitle 的 Tooltip 与 MarqueeText；录制、停止、试听、回到开头、撤销、重做、状态位置与两个设置图标统一放在同一行，底部“应用到音轨”固定。中间复用框架 Splitter，拖动分隔条调整演奏键盘与卷帘的高度，各自保留内部滚动。键盘根据当前模板显示有映射的整行；窄窗口同样保持单行顶部，键盘和卷帘在中间区域滚动，音轨名与应用按钮固定，纵向滚动容器接入公共返回顶部入口。

模板选择收在顶部键位映射图标的 Popover 内；键位映射与录制方式图标紧邻撤销、重做，统一归入操作按钮区，状态与位置展示在其右侧。“录制方式”使用 Wrench 扳手图标，Popover 顶部选择接着录、从光标补录或重录选段，旁边的 Tooltip 随当前方式说明语义；选择重录后，下方立即显示起止小节，切回其他方式后收起范围设置。倒数、节拍器与伴奏也放在同一浮层中。顶部同时展示紧凑操作、状态、位置与音符数量。点击“录制帮助”打开 Modal，复用 SectionDocument：左侧目录独立滚动，点击后右侧正文平滑定位；目录导航保持路由不变。帮助包含快速开始、录制方式、预览与布局、草稿与应用、快捷键五部分。卷帘用于查看录入结果、跟随录制与点击定位，下一层 MIDI 编辑器负责完整音符编辑。

默认“接着录”从最后一个有效音符结束处开始，空轨从区域起点开始。没有倒数时首个映射键启动音乐时间，首键前和停止前等待不写入曲目，内部休止保留；跟拍录制保留计时后的空拍。暂停释放所有声音；自由录制继续时首键接在上次音符末尾。一小节倒数从音频时钟启动，倒数中按住的键不跨界写入，结束后的空拍保留。

“从光标补录”从点击卷帘定位的光标处叠加音符；“重录选段”在录制方式图标浮层中选择起始、结束小节。起始小节包含，结束小节不包含，例如 1 到 3 表示录制第 1–2 小节。范围按当前速度与拍号时间轴转换为半开区间 `[start, end)`，跨界旧长音拆分保留外部，完全没有新音符时不替换。提前停止保留未录满的空白，到范围末尾自动停止。暂停后更换录制方式会先收尾当前录音，保持原来的录制方式；每次停止录制可本地撤销，宿主应用为一条撤销。

录制和暂停中的同一次录音锁定映射。录制中锁定会影响录入结果的设置和撤销操作；暂停后撤销先收尾当前录音。应用失焦、最小化和安装准备会暂停并释放音符；Escape 在录制中停止录音。关闭有修改的抽屉默认保留在工作区，也可应用并关闭或放弃。

## 键盘与便捷操作

先点击“开始录制”或使用组合快捷键，再按演奏键盘中的映射键输入。按住决定音符时长，同时按多个键录入和弦；录制开始后自动聚焦键盘，也可点击键盘重新获得焦点。“回到开头”将光标定位到音轨起点，配合“从光标补录”可再次叠加。试听用于检查当前录入结果，撤销／重做用于恢复或取消整次录入。基本操作提示集中在帮助文档中。

- `Ctrl/⌘+Enter`：开始录制、暂停或继续；开始／继续时聚焦演奏键盘。
- `Ctrl/⌘+Z`：撤销；`Ctrl/⌘+Shift+Z`：重做，演奏键盘聚焦时同样可用。
- `Escape`：设置浮层、帮助或关闭确认打开时先关闭当前层；录制中停止，停止后关闭工作区并按修改状态确认去留。

映射的 `Space`、`Tab`、`Enter` 等按键优先用于演奏；输入框、下拉、菜单中的键盘操作保持组件语义。录制快捷键使用组合键，避免占用常用映射键。

## 组件与服务边界

- `TrackRecorderLauncher.openTrackRecorder()` 接收宿主快照和持久化／结果回调，锁定宿主后打开 `TrackRecorderDialog`。
- `TrackRecorder` 是无 DOM、无 Store 的状态机，持有独立 `EditorSession`、按键来源配对、局部重录、撤销和检查点。
- `RecorderAudio` 注入音色准备、音频时钟、独立声音句柄、伴奏和节拍器；复用现有 soundfont。节拍器以音频锚点提前排程，界面刷新只显示游标和推动排程。
- UI 复用已安装的 `antdv-next 1.3.3` Drawer／Popover／Splitter／Modal、受控 `KeyTemplateSelect`、可按住的 `KeyboardPreview` 与公共 `PianoRoll` 的只读预览。录制帮助通过 `RecorderHelpDialog` 复用 `SectionDocument` 的目录与正文滚动，精细编辑沿用 MIDI 编辑器的检查器和菜单。未新增第三方录制或 MIDI 写入依赖。
- 主窗口保留项目权威会话，独立窗口一次请求准备和一次提交完整结果；按键事件不走 IPC。刷新或销毁独立窗口时解除旧锁定。
- `applyRecorderResult` 校验项目 ID、音轨和快照哈希，先保存候选主草稿，再执行公共 `apply-track-edit`。版本不匹配或磁盘错误保留录制内容，允许另存副本。

推荐映射保存在可选 `MidiProject.extensions.keyboardRecording.template`，保存完整快照；原模板删除后可继续使用。旧项目不需要扩展字段。JSON、复制、草稿及 Rust 持久化保留扩展，标准 MIDI 仅保留音乐。

## 草稿与输入生命周期

录制草稿按项目和音轨生成 `recording-<SHA256>` 文件键，每秒变更保存，与主编辑器草稿分离。新项目打开录制前先保存主基线，确保重启后项目身份可恢复。按住的音符按检查点时刻结束；检查点使用音乐区域边界，不保存卷帘浏览留白。应用、放弃及恢复副本期间暂停周期检查点并锁住编辑，先排空已有写入再删除；主草稿接受结果后才删除录制草稿，删除失败允许重试且锁住已应用内容。

物理键盘与鼠标使用来源引用计数，同一映射键最后一个来源释放时才结束，鼠标移出键位即释放该鼠标来源。忽略系统重复键。输入框、下拉及菜单保持正常键盘操作；只有聚焦演奏键盘时拦截映射的 Space／Tab／Enter／方向键／功能键。异步音色准备受会话代数及来源 token 限制，释放、暂停或取消后不会迟到发声。

打开录制帮助前先暂停并释放声音。帮助 Modal 显示时，键盘操作仅作用于帮助弹框，背景录制快捷键与映射输入保持隔离；`Escape` 只关闭帮助。

## 验证

公共编辑包测试覆盖原子应用、元数据撤销、显式区域及相对选择；录制测试覆盖首键、休止、暂停、和弦、多来源、倒数、速度变化、最短音符、越曲尾、边界拆分、空重录、草稿恢复、异步取消、保存失败与过期结果。Playwright 验收需覆盖全内容区抽屉、音轨名与所有操作保持单行、固定首尾、面板滚动、分隔条调整、模板对应键盘行、窄窗口、录制方式浮层切换后即时显隐重录范围、只读预览定位、映射键与组合快捷键、重录小节范围、帮助目录与正文独立滚动、无路由 hash，以及取消隔离、主窗口与独立窗口应用／撤销。Rust 测试验证旧工程和扩展持久化往返。

录制 UI fixture 注入可控音频服务；既有窗口播放交接回归保留真实音色、AudioContext 和音频时钟，在 Chromium 中使用无声输出设备，避免依赖宿主声卡。浏览器自动化不能代替实际声音和游戏设备验收。

手工桌面验收还需确认实际 soundfont 声音与游戏键盘输入：多个键和鼠标按住、焦点离开、倒数伴奏、模板切换、小节重录、分隔条与内部滚动、帮助目录、快捷键，以及关闭取舍与草稿恢复。
