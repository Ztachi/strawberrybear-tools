## 自动化覆盖

| 范围     | 已实现的验证                                                                                                                   |
| -------- | ------------------------------------------------------------------------------------------------------------------------------ |
| 检测     | 单源正文超时、HTML、坏 JSON、缺平台；失败源不丢弃有效源；SemVer 选择较高版本；全部失败不得误报最新                             |
| 下载     | 使用官方更新器与本地故障服务器；截断重试后切源；停滞、连接失败、未知长度；签名失败不重试同源，全部失败不提供安装字节           |
| 生命周期 | 原生启动检查不依赖音频；下载/待安装/安装去重；恢复事件 5 分钟节流；取消使旧任务代数失效；前端拒绝迟到快照                      |
| 安装保护 | 保存取消、保存失败保留下载；重复点击只确认一次；未挂载保护禁止安装；不在下载安装返回时宣称成功                                 |
| 发布     | 版本值比较、同提交草稿恢复、禁止已公开版本重建和版本回退；平台、产物、签名、链接缺失；固定入口逐个上传校验，失败不替换另一清单 |
| 界面     | 独立注入适配器；检查失败、下载取消/恢复、待安装、未知总长度、上次更新未生效；中英文布局                                        |
