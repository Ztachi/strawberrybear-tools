# 首页体验与视觉规范

## 定位

首页是“奇迹大陆搭配师协会总部 · 证书签发处”的正式办事入口，不是资料库看板或工程状态页。首屏必须同时表达协会权威、少女向清透华丽感、以及办理流程的明确性。

## 顶部栏

- 品牌区整体可点击返回首页，点击范围包含 logo、主标题和副标题。
- 顶部标题采用两级结构：主标题为“奇迹大陆搭配师协会总部”，副标题为“证书签发处”。
- 顶部右侧只保留高频全局入口，例如语言切换和个人中心；“办事首页”“继续办理”等低频按钮不放在顶部。
- 小屏标题允许省略号截断，但必须保留主副层级，不能把完整标题压成一行。

## 首页主操作

- “登记资料”是首页唯一主 CTA，样式保持高质感胶囊按钮，可带轻微呼吸和高光动效。
- 主 CTA 在移动端保持文档流布局，不能 fixed 覆盖正文、流程或证书样例。
- 如果存在未完成草稿，点击主 CTA 必须先提示用户“重新登记”或“继续办理”；用户选择继续后才进入草稿所在阶段。
- 用户选择“重新登记”时必须再次确认，明确提示当前未完成数据会被删除，确认后才清除草稿并从第一步开始。
- 草稿提示属于首页局部交互，不需要抽成全局 composable。

## 办理流程

- 首页只展示轻量流程提示，不放正式步骤条，避免把办事入口做成流程页。
- 登记资料后的办理页必须有统一流程导航。可优先评估 Vuetify Stepper；若默认结构难以满足布局、换行、连线和交互要求，应使用项目私有步骤条组件。
- 流程导航放在流程壳页面顶部，下方承载“身份登记、档案核对、正本签发、领取证书”等步骤内容。
- 步骤内容可以是独立页面，也可以是流程页内部组件；复杂表单步骤优先拆成 `views/CertificateWorkflowView/components/*Step/` 这类页面私有组件。
- 流程页顶部步骤条必须保持稳定，步骤切换过渡和滚动条只发生在底部内容区域。
- 流程导航样式应融入粉白、金蓝、柔光阴影和圆角，不使用默认后台管理感的硬边样式。
- 已到达步骤必须可点击往返切换，未到达的后续步骤不可跳过；可点击范围基于当前草稿已到达的最远步骤，而不是只基于当前 URL。
- 每个步骤必须有专属图标；已完成步骤还要显示明确的钩图标。图标优先使用 Vuetify `v-icon` 和 MDI 图标名，例如 `mdi-check-bold`，参考 Vuetify Icons：https://vuetifyjs.com/en/components/icons/#examples
- 步骤标题在桌面和移动端都不能逐字竖排；长标题或英文文案应自然换行，不产生页面级横向滚动条。
- 证书办理页的步骤条应使用 `position: sticky` 留在顶部；吸顶时通过 `@container scroll-state(stuck: top)` 收缩样式，优先展示图标，并用 Vuetify Tooltip 展示步骤标题与说明。

## 返回顶部

- 应用右下角提供全局返回顶部浮动按钮，使用 Vuetify Floating Action Button 形态，并搭配 Tooltip 说明操作。
- 返回顶部按钮不直接耦合某个页面 DOM。页面通过 `useScrollTopControl` 注册自己的滚动容器、展示阈值和滚动行为，Pinia 只负责展示状态和返回顶部请求。
- 默认滚动容器是 `window`；如果页面确实有独立滚动区域，页面组件可以把对应容器 `ref` 传给 hook。
- 全局 FAB 的展示阈值必须可配置，避免不同页面内容高度和滚动容器差异导致按钮过早或过晚出现。

## Tooltip

- Vuetify Tooltip 通过 `createVuetify({ theme, defaults })` 统一配置 `color`、`location` 和 `contentProps`，不在单个页面或单个组件里临时改颜色。
- Tooltip 的背景/前景色优先走 Vuetify theme token，例如 `tooltip` 与 `on-tooltip`；圆角、边框、阴影这类内容层样式优先放到 `VTooltip.contentProps`。
- 不要直接覆盖 `.v-tooltip > .v-overlay__content` 这类 Vuetify 内部结构选择器；只有 theme、defaults、props、slots 都无法表达时，才使用项目自有 class 写窄范围 CSS。
- Tooltip 文案必须保持深色、高对比度，背景使用浅色半透明卡片感，避免在粉色柔光背景上出现低可读性。

## Vuetify 主题与默认配置

- 颜色、前景色、圆角变量和组件默认 prop 优先放在 `src/theme/vuetify.ts`，参考 Vuetify Theme 与 Defaults 能力统一配置。
- 组件已经提供的能力优先使用框架实现，例如 `v-fab`、`v-tooltip`、`v-icon`、主题色和组件默认值；只有业务交互或布局表达确实不匹配时才自定义组件。
- 全局 CSS 只负责页面基础背景、品牌纹理、复杂渐变、动画和项目自有 class；不要为了改一个 Vuetify prop 能解决的问题去覆盖内部 DOM。
- 如果必须覆盖第三方组件内部结构，先确认没有 theme、defaults、props、slots 或 exposed class 能表达，再写窄范围注释说明原因。

## 视觉语言

- 使用清透粉白作为底色，金色表达协会仪式感，蓝色表达证书权威感，少量紫色或薄荷色用于梦幻点缀。
- 装饰图形以细线、柔光、证书边角、星光为主，避免大面积单色渐变和工程化状态卡。
- 成品证书图必须完整可见，移动端居中展示，不能被按钮或绝对定位裁切。
- 动效用于入场、证书轻浮动和按钮高光，节奏轻柔；必须提供 `prefers-reduced-motion` 降级。

## 实现约束

- 新增布局、间距、响应式优先使用 Tailwind 原子 class。
- scoped CSS 只用于关键帧、伪元素、复杂渐变和 Vuetify 内部结构的窄范围装饰。
- 页面私有组件放在 `views/HomeView/components/` 下；Hero 内部子组件继续按父子层级递归放置。
- 首页状态只在确有复用或明确副作用边界时抽 composable，普通局部状态留在组件内。
