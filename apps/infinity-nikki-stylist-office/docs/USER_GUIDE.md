## 1. 这是什么

"奇迹大陆搭配师协会总部 · 证书签发处"是面向《无限暖暖》玩家的搭配师身份登记与证书签发 Web App。你可以在浏览器里完成四步流程：

1. 登记搭配师档案（姓名、称号、头像、背景、登记地区、会长签章）
2. 在证书图上核对档案
3. 让协会为你正式签发证书
4. 领取可下载、可收藏的证书正本

整个流程在浏览器内完成，不依赖服务器存储你的业务数据。所有草稿、已签发证书、自定义素材都保存在当前浏览器的本地数据库中（IndexedDB）。

适合场景：

- 想要一份"奇迹大陆搭配师"主题的虚拟身份凭证
- 在社群中分享自己的搭配师档案
- 收藏不同登记地区、不同称号下的搭配师身份

## 2. 整体办理流程

```text
首页 ──► 身份登记 ──► 档案核对 ──► 正本签发 ──► 领取证书
  │         │            │            │            │
入口    填写资料    在证书图上     协会仪式化      下载 16:9
        选素材     点击热区      自动签发       或 A4 正本
        创建草稿    修改资料      正式编号
```

任何一步都可以在"个人中心 → 我的证书"里查回历次已签发记录。

## 3. 界面总览

### 3.1 顶部栏

顶部栏是全局导航，从任何页面都能访问：

- **左侧 Logo + 协会名称**：点击会回到首页（首页按钮）
- **右侧语言下拉**：切换 UI 语言（简体中文 / 繁體中文 / English / 日本語）
- **右侧个人中心按钮**：打开"个人中心"

> 语言下拉只控制**界面文案**；证书上的语言在登记页单独选。详见 [11. 多语言](#11-多语言)。

### 3.2 首页

首页是入口和仪式化引导页，主要内容：

- 协会介绍与流程说明
- 当前是否有未完成的草稿
- "登记资料"主按钮（如果已有草稿，会提示"继续办理"还是"重新登记"）
- 协会证书正本示例图

### 3.3 身份登记页

办理流程第一步。集中展示登记表单：

- 搭配师姓名
- 搭配师称号（可更换，已为你随机预选）
- 头像选择
- 背景选择
- 登记地区
- 协会评语（自动随机选定）
- 会长签章（图片/文字双模式，可编辑）
- 资料确认按钮

详见 [5. 第一步：身份登记](#5-第一步身份登记)。

### 3.4 档案核对页（签发前校样）

办理流程第二步。**核心交互是直接在证书图上点击热区修改资料**：

- 不再提供侧边字段编辑面板或模板定位面板
- 只保留"返回登记资料"和"确认校样并进入签发"两个流程按钮
- 可编辑区域（头像、姓名、证书编号关联的登记地区、搭配师称号、会长签章）由模板 manifest 声明
- 可编辑区域常驻轻量标记，悬停/聚焦/触摸后提示更明确
- 移动端支持双指缩放、拖拽查看证书

详见 [6. 第二步：档案核对](#6-第二步档案核对)。

### 3.5 正本签发页

办理流程第三步。仪式化页面：

- 列出签发前的档案快照
- "确认正式签发"按钮启动签发流程
- 签发过程分阶段（封存档案、复核称号、编录编号、加盖印章、会长签章、正本下发），每阶段有进度提示
- 签发完成后显示"领取证书"按钮

详见 [7. 第三步：正本签发](#7-第三步正本签发)。

### 3.6 领取证书页

办理流程第四步。提供两种正本：

- 16:9 收藏版（适合分享、社群头像、壁纸）
- A4 打印版（适合打印装裱）

详见 [8. 第四步：领取证书](#8-第四步领取证书)。

### 3.7 个人中心

管理历史证书、自定义资料、本地数据的总入口。详见 [9. 个人中心](#9-个人中心)。

## 4. 首次使用流程

第一次打开应用时，建议按下面流程操作：

### 步骤 1：等待资源预热

应用首次打开会预热关键资源（证书模板、协会素材），通常只需几秒钟。预热期间会显示"正在准备证书模板 / 正在准备协会素材 / 正在开启签发处"三段提示。

预热完成后，模板和协会素材会进入浏览器的离线缓存（详见 [12. 离线与资源更新](#12-离线与资源更新)）。

### 步骤 2：从首页开始登记

点击首页的"登记资料"主按钮，浏览器会创建一份新的办理草稿，并跳转到登记页。

如果之前已经有未完成的草稿，会先弹出"继续办理 / 重新登记"对话框。

### 步骤 3：完成四步办理

依次完成身份登记 → 档案核对 → 正本签发 → 领取证书。每一步都可以在"个人中心"里查回历史。

## 5. 第一步：身份登记

### 5.1 填写搭配师姓名

- 在"搭配师姓名"输入框内填写你想要的姓名
- 限制：最多 14 个用户可见字符
- **姓名不会被翻译**——一旦写入，就是证书上的原文

### 5.2 选择搭配师称号

- 点击"搭配师称号"区域，打开称号选择弹窗
- 称号会显示在证书的"证书等级"位置
- 系统已为你随机预选一个，可以在这里换成协会认证的其他称号
- 当前已上线的称号来自协会资料库，可通过"个人中心 → 协会资料库"查看总数和版本

### 5.3 选择头像

- 点击"头像"区域，打开头像选择弹窗
- 头像分为两组：
  - **协会头像**：协会内置官方头像
  - **自定义头像**：你之前在"自定义资料"中上传并裁剪过的头像
- 如果没有自定义头像，组内会显示"暂未添加自定义素材"
- 可以点击"随机选定"快速挑一个

### 5.4 选择背景

- 与头像选择弹窗类似，分"协会背景"和"自定义素材"两组
- 自定义背景在"自定义背景管理"中维护

### 5.5 选择登记地区

- 登记地区影响证书编号中的地区代码（前缀由地区 code 决定）
- 地区译名来自官方 Pear-Pal 地图配置，并随 UI 语言自动切换
- 当前已收录花愿镇、微风绿野、小石树田村、石树田无人区、祈愿树林等多个奇迹大陆地区

### 5.6 协会评语与会长签章

- **协会评语**：草稿创建时由系统自动随机选定，你不需要手动改
- **会长签章**：新草稿默认使用"图片签章"，并选中第一套协会内置签章
- 点击签章区域会打开"修改会长签章"弹窗，弹窗内有两个页签：
  - **图片签章**：可选择协会内置签章或自定义签章；协会内置签章会随证书语言切换对应图片
  - **文字签章**：可输入最多 6 个用户可见字符；没有默认文字，留空确认时会提示"会长签章不能为空"
- 弹窗内的修改会先保存在临时状态，点击"取消"不会写入草稿；点击"确认"才会保存当前页签的签章模式
- 图片签章和文字签章会分别保留上一次选择，再次打开时会停在当前草稿正在使用的签章模式

### 5.7 资料确认

所有字段确认后，点击"确认无误，编制校样"按钮进入下一步。点击后：

- 档案从"填写中"变成"已确认"
- 流程自动跳到第二步"档案核对"
- 之后仍然可以在核对页通过点击热区继续修改

如果发现要改的字段比较多，也可以点"返回修改"留在登记页。

## 6. 第二步：档案核对

档案核对页是**整条流程里最特殊的页面**：没有侧边栏、没有表单字段，全部交互都在证书图上。

### 6.1 在证书图上点击热区

证书图上会有几块带轻量标记的可编辑区域：

- **头像**：点击打开头像选择弹窗
- **姓名**：点击打开姓名编辑弹窗
- **证书编号关联的登记地区**：点击打开地区选择弹窗
  - 证书编号本身不直接编辑——切换登记地区会改变编号前缀
- **搭配师称号**：点击打开称号选择弹窗
- **会长签章**：点击打开签章选择弹窗，可在图片签章和文字签章之间切换

每个弹窗都带有"原样写入证书，不会随语言切换翻译"或"登记地区会影响证书编号中的地区代码"等说明。

### 6.2 移动端手势区分

在手机端查看证书时，需要区分"点击编辑"和"查看手势"：

- **单击热区**：打开对应编辑器
- **双指缩放 / 拖拽**：缩放和移动证书图，不会触发编辑
- **建议横屏**：横屏能更好地查看证书细节，竖屏缩放后再操作更顺手

### 6.3 顶栏语言切换同步切换证书底图

在核对页切换顶栏的 UI 语言，证书底图（`zh-CN.png` / `zh-TW.png` / `en-US.png` / `ja-JP.png`）和文字坐标会同步切换。**你的姓名不会被翻译**。

如果当前使用协会内置图片签章，签章图片会跟随证书语言切换；如果当前使用文字签章，文字会保持你输入的原文。

确认无误后点击"确认校样并进入签发"，流程进入第三步。

## 7. 第三步：正本签发

### 7.1 签发流程

签发前会先展示档案快照（搭配师姓名、登记地区、称号、头像、背景、会长签章），用于最后一次核对。

点击"确认正式签发"后，进入仪式化签发页面，分 6 个阶段：

1. 封存档案：校样档案正式封存
2. 复核称号：认证称号通过复核
3. 编录编号：正式编号完成编录
4. 加盖印章：协会金章确认生效
5. 会长签章：会长签章写入证书
6. 正本下发：正式证书准备交付

每个阶段都有进度提示，签发完成后显示"领取证书"按钮。

### 7.2 签发未完成怎么办

如果签发过程中出现异常（比如断网），页面会显示"签发未完成"。此时：

- 草稿仍然保留在本地数据库中
- 可以稍后重试签发
- 也可以返回"档案核对"继续修改

## 8. 第四步：领取证书

### 8.1 16:9 收藏版与 A4 打印版

协会为每张证书封存两种正本：

- **16:9 收藏版**：分辨率较高，适合作为电子壁纸、社群头像、社群分享
- **A4 打印版**：按 A4 比例排版，适合打印装裱

通过页签切换两种版本。

### 8.2 下载正本图片

点击"下载当前正本"按钮，浏览器会保存当前展示的正本图片到本地。下载的图片是当前可见版本的 PNG。

## 9. 个人中心

个人中心通过顶部栏的"个人中心"入口进入，有 4 个页签：

### 9.1 我的证书

列出所有已签发的搭配师证书，每条记录包含：

- 证书编号
- 搭配师姓名
- 搭配师称号
- 签发时间
- 操作按钮：查看证书 / 删除

支持按姓名、编号或称号搜索。

### 9.2 自定义资料

管理你上传并裁剪过的头像和签章，并可按素材类型筛选。详见 [10. 自定义头像与签章管理](#10-自定义头像与签章管理)。

### 9.3 本地数据

展示当前应用占用的浏览器存储情况：

- **本应用数据**：草稿、已签发记录、自定义素材、资料库缓存、正本图片的条目数
- **浏览器存储容量**：当前应用占用的存储 / 浏览器分配的配额
- **离线资源缓存**：当前 Service Worker 缓存的资源大小（生产构建才有；开发模式显示"开发模式已禁用"）

可执行三个操作：

- **导出数据**：把当前所有本地数据打包成 zip 文件下载，用于备份或换机迁移
- **导入数据**：从 zip 备份恢复本地数据
- **清除缓存**：只清除可重建的离线资源（模板、协会素材、资料库缓存），不影响草稿和已签发记录
- **清除数据**：删除所有本地数据（草稿、已签发记录、自定义素材、设置），操作不可撤销

### 9.4 协会资料库

展示当前应用内置资料库的基础信息：

- 资料库版本
- 称号数量
- 模板数量

后续远程更新、导入导出、资料维护都会归入此处。

## 10. 自定义头像与签章管理

### 10.1 上传新头像或签章

1. 进入"个人中心 → 自定义资料"页
2. 选择"自定义头像"或"自定义签章"筛选
3. 点击"添加头像" / "新建头像"，或点击"添加签章" / "新建签章"
4. 选择一张本地图片（PNG / JPG）
5. 输入素材名称（例如"我的搭配师头像"或"我的会长签章"）
6. 进入裁剪步骤

如果你是从登记页或校样页的签章弹窗进入自定义签章管理，保存并选用后会自动回到来源页面，并重新打开签章弹窗。

### 10.2 裁剪头像

- 裁剪框比例会匹配当前证书头像区域（保证头像在证书上不被拉伸或裁切错位）
- 移动四角和四边可以调整裁剪范围
- 保存时会同时保留**原图**和**裁剪版**
- 点击"保存并选用"会同时把当前档案的头像切到这张图

### 10.3 裁剪签章

- 裁剪框比例来自当前模板签章配置，内置模板使用 `2172 × 724`
- 建议使用透明 PNG，这样签章能自然叠在证书底图上
- 保存时会同时保留**原图**和**裁剪版**
- 点击"保存并选用"会同时把当前档案切到图片签章模式，并选中这张自定义签章

### 10.4 自定义背景

自定义背景仍在"自定义背景管理"中维护，与头像/签章管理类似，区别是：

- 背景建议 16:9 比例（推荐 3840 × 2160，最低 1920 × 1080）
- 不需要裁剪步骤，直接上传即可
- 保存后可从登记页/校样页的背景选择层选用

## 11. 多语言

### 11.1 UI 语言

通过顶栏右侧的语言下拉切换 UI 语言。应用支持：

- 简体中文（zh-CN）
- 繁體中文（zh-TW）
- English（en-US）
- 日本語（ja-JP）

切换会立即刷新界面文案，但**不会改变证书上的语言**。

### 11.2 证书语言

在登记页单独选择证书语言。新草稿的默认证书语言取自创建时的 UI 语言。

切换 UI 语言不会自动改已经创建好的草稿；如果你想在登记后切换证书语言，回到"身份登记"页重新选一次即可（已经选择头像/背景/签章会被保留）。

### 11.3 姓名与文字签章不被翻译

搭配师姓名和文字签章是你在登记页或校样页填入的原文，**不会随 UI 语言或证书语言切换而被翻译**。这是为了保证协会对搭配师身份的认证一致性。

图片签章不同：协会内置图片签章会按证书语言切换对应图片，自定义图片签章则始终使用你保存的那张图。

## 12. 离线与资源更新

### 12.1 首次加载

应用首次打开会预热关键资源，包括：

- 证书模板（多语言底图）
- 协会头像、协会背景、协会签章
- 签发页素材
- 资料库种子

预热完成后，这些资源会进入浏览器的 Service Worker 缓存。**首次准备完成后，常用素材可离线使用**。

> 开发模式下（`pnpm dev`）会主动注销 Service Worker 并清理离线缓存，以避免旧缓存接管 Vite HMR。所以开发时"离线资源缓存"显示为 0B 或"开发模式已禁用"是正常现象。

### 12.2 资源包更新提示

当协会更新了模板或素材时，新版本会被部署到线上。再次打开应用时，浏览器会检测到 Service Worker 有新版本：

- 应用不会强制打断当前页面
- 底部弹出"证书资源包已更新，刷新后即可使用新模板和素材"提示
- 点击"立即更新"，应用会切换到新缓存并刷新页面

如果暂时不更新，当前页面继续使用旧缓存，不影响本次操作。

### 12.3 离线缓存范围

- **应用入口页、模板包、资料库**：network-first（在线时优先拿最新，离线时回退缓存）
- **其他同源静态资源**：stale-while-revalidate（先展示已有缓存，后台更新下次可用缓存）
- **关键资源清单**：集中在 `src/domain/offline/resources.ts`，Service Worker 预缓存清单在 `public/sw.js`

只有同源资源会被缓存；你的草稿、已签发证书、自定义头像和自定义签章仍然在 IndexedDB 里，不归 Service Worker 管。

## 13. 数据与隐私

### 13.1 数据保存在哪里

| 数据类型             | 存储位置                                  | 备注                       |
| -------------------- | ----------------------------------------- | -------------------------- |
| 草稿                 | IndexedDB（`activeDraft` 表）             | 唯一办理草稿               |
| 已签发证书           | IndexedDB（`issuedCertificates` 表）      | 含正式编号、地区、签发时间 |
| 自定义头像/签章/背景 | IndexedDB（`customAssets` 表）            | 保存原图 + 裁剪版          |
| 资料库缓存           | IndexedDB（`catalogVersions` 表）         | 按版本缓存                 |
| 证书 PNG 正本        | IndexedDB（`certificateImages` 表）       | Blob 单独存放              |
| 本地设置             | IndexedDB（`settings` 表） + Pinia 持久化 | 轻量 UI 偏好由 Pinia 管    |
| 离线资源缓存         | Service Worker / Cache API                | 模板、协会素材、资料库     |

**应用不依赖服务端处理你的业务数据**——所有这些数据都在当前浏览器的本地数据库里。

### 13.2 导入与导出

通过"个人中心 → 本地数据"操作：

- **导出数据**：把所有 IndexedDB 数据打包成 zip 文件下载
- **导入数据**：从之前导出的 zip 恢复本地数据

> 导入会覆盖当前本地的对应数据。导入前建议先做一次导出备份。

### 13.3 清除本地数据的影响

清除本地数据前请确认：

- 草稿（如果当前正在办理某份档案）会被删除
- 已签发的所有证书记录会从本机移除
- 自定义头像、自定义签章和自定义背景会从本机移除
- 本地 UI 偏好（语言、主题、滚动位置等）会被重置

已下载到本地的正本 PNG 文件不受影响。

## 14. 常见问题

### 14.1 草稿丢失/没看到之前填的资料

可能原因：

- 切换了浏览器或设备：草稿只在创建时使用的浏览器里，换浏览器看不到
- 清除了浏览器站点数据：清空浏览器数据会连同 IndexedDB 一起清掉
- 重新登记时确认了删除：重新登记会先删除旧草稿
- 使用了无痕/隐私模式：无痕模式下 IndexedDB 在关闭窗口后会被清理

建议养成习惯：办理过程中点击"个人中心 → 本地数据 → 导出数据"做一次备份。

### 14.2 证书编号是怎么生成的

证书编号由 **登记地区 code** 派生：

- 每个地区有一个稳定的三位 code（如 `FLW`、`BRM`）
- 切换登记地区会改证书编号前缀
- 同一登记地区下的多份证书不会重复（编号由地区 code + 顺序号生成）

具体规则以协会资料库为准。

### 14.3 证书上的语言能切换吗

可以。在登记页选证书语言（与 UI 语言独立）。已经在校样/签发阶段想改：

- 校样页：直接在证书图上点登记地区热区，地区变化不会影响语言
- 证书语言：返回登记页重新选，姓名/称号/头像/背景/签章会保留

### 14.4 自定义头像或签章不显示怎么办

- 确认图片格式是 PNG / JPG
- 重新上传：进"个人中心 → 自定义资料"，找到该头像或签章点"编辑"，替换图片后重新裁剪保存
- 如果草稿里选中的自定义签章已经被删除，签章区域会提示不可用；请重新打开签章弹窗选一个可用签章
- 如果上传过程中页面崩溃，可清空浏览器缓存后重试

### 14.5 重新登记会保留之前的证书吗

会。已经签发的证书只受"清除数据 / 清除浏览器站点数据 / 切换浏览器"影响。**重新登记只删除当前未完成的草稿**，已签发的历史记录在"我的证书"里仍然能查回。

### 14.6 同步失败

应用不依赖服务端处理你的业务数据。失败通常发生在：

- 浏览器拦截了 Service Worker 注册
- 当前网络无法访问 `*.pages.dev`

排查方式：

- 检查浏览器是否屏蔽了 Service Worker（部分隐私模式/浏览器扩展会拦截）
- 检查网络是否能正常访问

### 14.7 移动端怎么更好地查看证书

- 校样页和领取证书页都支持双指缩放和拖拽
- 单击热区会进入编辑，长按不会
- 建议横屏查看证书细节；竖屏下可双指放大查看

## 15. 推荐使用顺序

第一次正式使用，建议按这个顺序操作：

1. 在首页等资源预热完成
2. 顶栏切到你常用的 UI 语言
3. 点击"登记资料"开始第一份档案
4. 在登记页填写姓名、选择称号、头像、背景、登记地区、会长签章
5. 资料确认 → 进入校样
6. 在证书图上点击热区核对每一项
7. 确认无误 → 进入签发
8. 等待协会签发完成
9. 领取证书，下载 16:9 收藏版或 A4 打印版
10. 在"个人中心 → 我的证书"里随时回看

如果想给同一角色申请多份不同地区/称号的证书，重复 3-9 即可，已签发的历史会保留在"我的证书"里。
