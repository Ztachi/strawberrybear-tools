# 架构与开发约定

## 职责

- Vue：主页、游戏 HUD、设置、教学、暂停、历史与劳动报告。
- Pinia：页面需要响应显示的对局摘要；逐帧物理状态不进入响应式状态。
- `src/game/engine`：Rapier2D 固定步长模拟、PixiJS 绘制、输入和碰撞事件。
- `src/game/systems`：材料、验收、事件选择与称号等纯业务规则。
- `src/db`：Dexie 存档、设置与历史记录事务。
- `src/config/balance.ts`：唯一数值平衡文件；物理、经济、事件、规则和称号参数集中维护。
- `src/config/board.ts`：只维护台面几何，不混入平衡数值。

## 坐标与素材替换

台面采用 720×1280 设计坐标，Rapier 世界按 20 像素/米换算。Pixi 根容器整体等比缩放，因此不同设备不会改变碰撞结果。

当前 `GameEngine` 用 `Graphics` 绘制占位形状。替换素材时保留刚体和碰撞体创建逻辑，仅将对应 `Graphics` 换为 `Sprite`，并让锚点和设计坐标保持一致。

## 存档一致性

每次验收先在内存固定评级、倍率、材料快照和收入，随后立即写入当前对局。完成对局时通过 Dexie 事务将固定结果写入历史并删除未结束存档，历史数据不随新配置重算。
