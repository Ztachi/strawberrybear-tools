# 素材替换清单

当前第一版已有 AI 生成的魔法花园台面底图 `src/assets/board-playfield.png`，轨道、机关、拍板、目标、弹珠和事件状态由 PixiJS 绘制，视觉坐标与碰撞体一致。后续素材继续通过 PixiJS Assets 加载，不修改碰撞体。

## 美术素材

| 分类 | 缺少素材                             | 建议格式          | 设计尺寸/说明              |
| ---- | ------------------------------------ | ----------------- | -------------------------- |
| 角色 | 萌园园弹珠（普通、碰撞、下班）       | WebP 序列或 Spine | 基准直径 72px，锚点居中    |
| 角色 | 大喵待命、救球、休息                 | WebP 序列或 Spine | 左右方向可镜像             |
| 台面 | 当前底图的最终压缩与分层前景         | WebP/AVIF         | 当前 PNG 约 2.4 MB         |
| 机关 | 农田、鱼塘、小动物窝                 | WebP/Spine        | 普通、命中、拒收、强化状态 |
| 机关 | 拍板、发射弹簧、下班弹弓             | WebP              | 保持现有旋转锚点           |
| 机关 | 三块目标、事件牌、借口牌             | WebP              | 升起/倒下两态              |
| 区域 | 陨星坑、验收通道、回环轨道           | WebP              | 入口需有清晰视觉导流       |
| 材料 | PRD 中 21 个材料图标                 | WebP/PNG          | 128×128，透明背景          |
| UI   | Logo、按钮纹理、HUD 图标、分享图装饰 | SVG/WebP          | 支持 2× 屏幕               |
| 教学 | 7 张操作示意图                       | WebP              | 竖屏阅读                   |

## 音频素材

| 分类     | 缺少素材                                    | 建议格式  |
| -------- | ------------------------------------------- | --------- |
| BGM      | 主页、游戏页循环音乐                        | OGG + M4A |
| 基础音效 | 当前合成音效的正式替换：蓄力/发射/拍板/弹弓 | OGG       |
| 机关音效 | 当前合成音效的正式替换：劳动装置/目标/验收  | OGG       |
| 收获音效 | 普通、稀有、巨陨星碎片                      | OGG       |
| 事件音效 | 当前事件提示音的八类差异化正式替换          | OGG       |
| 流程音效 | 当前救球/下班音效的正式替换，补称号与按钮   | OGG       |

`src/game/engine/audio.ts` 已离线合成并注册蓄力、发射、拍板、机关、目标、事件、验收、大喵救球和下班音效；它们受设置 Store 的统一音量和静音控制。正式素材就绪后替换对应别名，不需要改玩法代码。
