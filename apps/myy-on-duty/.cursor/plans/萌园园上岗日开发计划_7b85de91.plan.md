# 萌园园上岗日 第一版开发计划

## 总体策略

**一次性全量开发第一版完整闭环**：物理台面、玩法系统、主页、设置、存档、结算、报告、分享全部完整实现，按模块顺序推进。弹珠手感不阻塞其他模块——所有游戏数值（物理手感 + 经济平衡）集中在统一配置文件中，全部完成后最后单独微调手感与平衡性。

素材全部用代码绘制的占位图形，同步维护素材清单文档，后续直接替换贴图。

## 统一数值配置

所有可调数值集中在 `src/config/balance.ts` 一个文件（带 Zod Schema 校验 + 配置版本号），你后期调平衡只改这一个文件：

- 物理手感：重力、坡度、摩擦、反弹系数、最大安全速度、发射弹簧力量曲线、拍板力量/角速度、各主动机关弹力（普通/下班冲刺/拒收三档）、下班弹弓、陨星坑/验收/大喵弹射力度
- 经济数值：四个装置的材料掉落权重/价格/稀有度（常规 + 珍稀丰收 + 陨星丰收概率表）、验收倍率与权重
- 事件数值：八类事件的时长、冷却、触发权重、等待超时
- 规则数值：连续劳动判定时间、装置防抖间隔、验收冷却 10 秒、自动存档间隔
- 称号数值：四维权重、时间分曲线、星实映射阈值、称号分数区间

台面几何坐标单独放 `src/config/board.ts`（布局改动和数值调平衡是两类事）。游戏页内置开发调试面板（可开关），运行时热调 balance 参数，调好后回写文件。

## 技术栈落地

按选型文档执行，包名与接入方式确认如下：

- Vite + Vue 3 + TypeScript + Vue Router + Pinia + vue-i18n（先只写 zh-CN，key 全部就位）
- PixiJS 8（渲染）、`@dimforge/rapier2d-compat`（物理，WASM 内联版免 Vite 插件）、`@pixi/sound`（音频）
- Dexie（IndexedDB 存档）、Zod（配置与存档校验）、Vitest + Playwright（测试）
- UI 用 Tailwind 4 + 自定义游戏化组件，不引入 Vuetify
- 继承 `@strawberrybear/tsconfig`、根 ESLint、`@` 别名等 monorepo 规范

## 架构设计

```mermaid
flowchart TD
    VueViews[Vue 页面层：主页/游戏页外壳/弹层] --> PiniaStores[Pinia：HUD 状态/设置/暂停]
    PiniaStores <-->|事件总线 GameBridge| GameCore[游戏核心 src/game 纯TS]
    GameCore --> Physics[PhysicsWorld：Rapier2D 固定步长]
    GameCore --> Renderer[Renderer：PixiJS 插值渲染]
    GameCore --> Systems[玩法系统：材料/连击/验收/随机事件/大喵]
    GameCore --> AudioMgr[AudioManager：@pixi/sound]
    Systems --> Config[src/config：常量+Zod Schema]
    GameCore --> SaveSvc[存档服务] --> DexieDB[Dexie / IndexedDB]
```

## 模块 1：物理台面基础

- 脚手架：新建 workspace 应用、Vite/TS/Tailwind/ESLint 配置、路由骨架、`balance.ts` / `board.ts` 配置文件
- 固定时间步长游戏循环（accumulator + 渲染插值），Rapier2D 世界初始化
- 台面几何全部由 `src/config/board.ts` 坐标数据驱动（虚拟 720×1280 坐标系，等比缩放适配屏幕与安全区）：外墙、右侧发射通道 + 单向挡片、左右拍板、中央落口、左右内回球道/外侧下班道、下班弹弓、上方三个主动碰撞器（圆形保险杠）、左侧加班回环、陨星坑、三块目标牌、验收通道入口
- 拍板：kinematic 刚体角速度驱动，支持手机左右半屏触控 + PC 键盘 A/L/Space
- 发射弹簧蓄力/释放、力度不足回落
- 弹珠 CCD + 最大安全速度钳制，验证高速不穿透
- PixiJS 占位图形渲染（几何图形 + 文字标注），带物理调试开关

## 模块 2：玩法系统

- 材料系统：四个装置的掉落池/稀有度/防抖判定，材料反馈（普通/稀有/巨陨星三级）
- 连续劳动计数与最高记录
- 三块目标牌击倒 → 验收通道开启 → 捕获/评级(×1.2/1.3/1.4)/结算/弹回/10 秒冷却
- 八类随机事件（强制加班、今日超想要、暖暖查岗、下班冲刺、借口连发、珍稀丰收、陨星丰收、大喵重新上岗），事件调度器：权重、互斥、冷却、不连续重复
- 大喵保护（外侧下班道一次共享保护）、中央落口/外道结束判定
- 本局结束流程：拍板锁定、剩余材料 ×1.0 结算、称号算法（四维权重）、亮点提取

## 模块 3：UI 外壳与页面

- 资源加载页（进度/失败重试）、主页（开始/继续 + 五个悬浮按钮）
- 游戏页顶部信息栏、临时事件状态条
- 弹层体系：首次教学、玩法说明、设置（音量/语言/PC 键位映射）、关于、暂停（含恢复倒计时）、下班结算
- 暂停触发链：按钮/页面后台/失焦/弹层遮挡/返回主页
- vue-i18n 接入，全部文案走 zh-CN key

## 模块 4：持久化与数据一致性

- Dexie 表：未结束对局、历史记录、设置、累计统计，含配置版本号
- 定时自动存档 + 关页最终保存；继续游戏完整恢复（物理状态、事件剩余时间、验收状态等）
- 验收结算原子性（扣材料与加星实一体，防重复出售），Zod 校验存档

## 模块 5：劳动报告与分享图

- 公共劳动报告组件（结束结算/历史记录两种入口按钮差异）
- 游玩记录列表；分享图用离屏 Canvas 按单局记录动态生成 + 预览保存

## 模块 6：测试、文档与验收

- Vitest：掉落概率、事件规则、验收结算、称号计算、配置 Zod 校验
- Playwright：开始/继续/暂停恢复/历史记录/竖屏适配核心流程
- 应用 docs：架构说明、i18n 声明、**素材清单**（美术贴图逐项：萌园园/大喵/台面/机关/材料图标/UI；音频逐项：BGM/各音效，标注已有占位与替换方式）
- 音效尝试用脚本生成简易占位音效（jsfxr 风格合成），不满意的项留在清单中
- 更新 `docs/apps/myy-on-duty.md` 索引，按 PRD 第 27 节验收标准自查

## 收尾：整体联调与手感微调

- 完整流程走查（PRD 第 28 节完整流程逐步跑通）
- 弹珠手感与经济平衡微调：只改 `balance.ts`，配合游戏内调试面板热调，你确认手感后固化参数

## 关键风险与对策

- **弹珠手感**：参数全部集中在 `balance.ts`，配调试面板热调，与其他模块解耦，最后单独微调
- **拍板高速穿透**：CCD + kinematic 拍板 + 速度钳制，模块 1 即验证
- **暂停/恢复物理一致性**：物理状态序列化（位置/速度/角度）随存档保存，恢复后冻结再倒计时
